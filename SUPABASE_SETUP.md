# Ativar a comunidade do Tier Editor

A página de comunidade já está implementada, mas precisa de um projeto Supabase para armazenar publicações online. Sem essas credenciais, o editor e a biblioteca continuam funcionando normalmente, mas publicar/consultar listas públicas fica desativado.

## 1. Criar o banco

1. Crie um projeto gratuito em https://supabase.com/.
2. Abra **SQL Editor** e execute:

```sql
create table if not exists public.tier_lists (
  id bigint generated by default as identity primary key,
  title text not null,
  author text not null default 'Anônimo',
  board jsonb not null,
  created_at timestamptz not null default now()
);

alter table public.tier_lists enable row level security;

create policy "Public can view tier lists"
on public.tier_lists for select
to anon
using (true);

create policy "Public can publish tier lists"
on public.tier_lists for insert
to anon
with check (
  char_length(title) between 1 and 120
  and char_length(author) <= 60
  and pg_column_size(board) < 500000
);
```

## 2. Configurar o Vite

1. No Supabase, abra **Project Settings → API**.
2. Copie a **Project URL** e a chave **anon/public**.
3. Na raiz do projeto, crie um arquivo chamado `.env` com:

```env
VITE_SUPABASE_URL=https://SEU-PROJETO.supabase.co
VITE_SUPABASE_ANON_KEY=SUA_CHAVE_ANON_PUBLICA
```

4. Salve as variáveis nas configurações de ambiente do serviço de hospedagem (por exemplo, Vercel/Netlify) e faça um novo deploy.

A chave anon/public é destinada ao navegador; nunca coloque a chave `service_role` no site.

## Observações

- As publicações ficam visíveis para qualquer visitante.
- O envio é anônimo, com um campo opcional para nome/apelido.
- Para uma comunidade aberta maior, configure CAPTCHA, limites de publicação e moderação contra spam no Supabase antes de divulgar o site.
